尔湾出租房的 HOA 费和 Mello-Roos 一般谁付？能不能写进租约让租客付？

法律上都是业主的责任：HOA 的定期和特别评估费是「业主的债务」（Civil Code 5650），Mello-Roos 是对房产征收、印在县地税单上的特别税；租约可以约定由租客承担一部分钱，但对 HOA 和县政府来说，欠了还是找业主。

核对日期：2026年11月11日。本页是一般信息，不构成法律或税务意见。

两笔钱分别是什么

  • HOA 费：小区业主协会按规章向每个单位收的定期评估费（regular assessment），遇到大修还可能有特别评估费（special assessment）。Civil Code 5650 写明，这些费用连同滞纳金、催收费用和利息，是业主的债务。逾期 15 天算拖欠，协会可以收滞纳金和利息。
  • Mello-Roos：按 1982 年《Mello-Roos 社区设施法》成立的社区设施区（CFD）征收的特别税，用来支付当地公共设施的建设，通常以发行债券的方式融资。橙县税务局说明，这类特别税对房产征收，印在地税单的「Special Assessment Charges」一栏。尔湾市自己管理哪些 CFD 和评估区，以尔湾市官网和你的地税单为准。

写进租约让租客付，可以吗

租约是房东和租客之间的合同，可以约定租客承担某些费用，但这不会改变你对 HOA 和县政府的责任。实际做法上，多数房东把这两笔钱算进租金里报一个总价，原因很简单：

  • HOA 费和特别税会变，单列出来，每次变动都要和租客重新说清楚。
  • 租客没付，你照样要付，不然滞纳金和利息算在你头上。
  • 租金以外的收费，要在租约里写清楚金额和算法；它算不算租金的一部分、会不会受涨租上限影响，要按具体租约问律师。

租客违反小区规定被罚的，可以在租约里约定由租客承担，但 HOA 处罚时，书面通知的对象是业主。

房东和租客各该怎么做

  • 房东：查地税单的 Special Assessment Charges，确认有没有 Mello-Roos 和评估区费用
  • 房东：把 HOA 费、特别税、地税、保险算进定价，用出租还是卖的计算器看回报
  • 房东：如果要租客分担，金额、调整方式写进租约，并请律师看
  • 租客：签约前问清楚月租是不是总价，有没有另付给 HOA 的钱
  • 租客：不要直接把钱交给 HOA，除非业主和 HOA 书面确认

举个例子

这是为了说明规则而设的例子，不是真实客户。吴女士在尔湾 Great Park 附近有一套出租房，地税单上有 Mello-Roos，小区每月还有 HOA 费。她原本想在租约里写「HOA 由租客付」，后来考虑到 HOA 费明年可能调整、租客晚付的滞纳金也会记在她名下，改成把这两笔钱算进月租，报了一个总价，租约里写明租金包含 HOA 费。

常见追问

不建议。法律上欠 HOA 的是业主，租客交晚了、交错账户，滞纳金和利息都算在业主名下。Civil Code 5650 规定，逾期 15 天就算拖欠，滞纳金不超过拖欠金额的 10% 或 10 美元中较高者（规章定得更低的从低），利息年利率不超过 12%。

看橙县的地税单，Mello-Roos 列在「Special Assessment Charges」里，写有债券名称和发行机构的电话。尔湾市官网也列出了市里管理的 CFD 和评估区。

确认租约里写了同样的话，并问清楚是否还有其他按月付的钱，比如水、垃圾或设施费。只看广告上的月租，容易漏算。
