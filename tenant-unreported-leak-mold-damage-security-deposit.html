厨房水池下的垃圾处理器漏了几个月，租客没报，柜子泡烂长霉，房东能让租客赔，或者退租时从押金里扣吗？

看情况：垃圾处理器坏了、漏水，修理通常是房东的事；但如果租客能发现漏水却几个月不报，让损坏一路扩大，多出来的损失房东可以主张由租客承担，从押金里合理扣除或另外索赔，前提是证据充分、金额合理。

本页条文核对日期：2026年11月11日。本页是一般信息，不构成法律意见。

法律上怎么分

  • 房东：要让水管和设施保持正常可用（Civil Code 1941.1(a)(2)）。处理器老化、自己坏了，修理由房东负责。
  • 租客：要正确使用水电煤气设施（1941.2(a)(3)），并为自己缺乏一般注意造成的损坏负责（Civil Code 1929）。
  • 加州地产局的租房指南也提醒租客，发现漏水或怀疑发霉要通知房东。

所以常见的争议点在于：租客是不是“应该发现而没有报”。水槽下天天开柜门拿东西，长期漏水和异味通常不难察觉；藏在墙里的漏水，就难说了。

从押金里扣，要满足什么

  • 只能扣租客或其客人造成的、超出正常磨损的损坏，金额限于恢复到入住时状态所需的合理费用，不能借机换新（Civil Code 1950.5(b)、(e)）。
  • 拍照：2025 年 7 月 1 日以后开始的租约，入住前要拍；退房后维修前、维修后也要拍（1950.5(g)）。
  • 退租后 21 天内给逐项扣款明细，附发票或收据和照片；维修 21 天内做不完，可以先按善意估价扣，完工或拿到单据后 14 天内补齐（1950.5(h)）。
  • 恶意扣押金，法院最多可判两倍押金的赔偿（1950.5(m)）。

霉要先处理

不管最后谁赔，漏水和霉都要先修。会影响居住或健康的霉，属于房东要处理的居住条件问题。先修，再分责任。

房东该怎么做

  1. 马上关水、找人修，拍照和录像，带日期。
  2. 请维修人员书面写明漏水原因和大概持续多久。
  3. 保留发票，柜子的原始状况和使用年限也要有记录。
  4. 按 21 天规则出明细；超过押金的部分另行索赔。
  5. 新租约里写明发现漏水要及时报修。

举个例子

这是为了说明规则而设的例子，不是真实客户。周先生的租客退房时，他发现水槽下的柜子底板泡烂长霉。维修师傅书面说明：处理器接口老化渗漏，从水渍和霉的范围看已持续较长时间。周先生自己承担更换处理器的费用，柜子底板和防霉处理的费用，他按租客长期没报导致损坏扩大来主张，附照片、师傅说明和发票，在 21 天内寄出扣款明细。租客如果不同意，可以去小额法庭，由法官看证据决定。

常见追问

可以主张，但难度更大。依据是租客要为自己缺乏一般注意造成的损坏负责（Civil Code 1929），关键看证据能不能说明他应该发现而没有报。

不能借机换新。扣款限于把房子恢复到租客入住时状态所需的合理金额，正常磨损不能扣（Civil Code 1950.5(e)）。

超出押金的部分可以另行向租客索赔，例如在小额法庭起诉。能不能拿到，取决于证据。
