房东问答 Landlord Q&A

租客在出租房里偷偷开月子中心，被邻居举报到 HOA 或管理处，房东要担什么责任？能不能据此收回房子？

房东可能同时面对 HOA 处罚、市政府执法和保险不赔的风险，而且这些通常先找业主；能不能收回房子，要看租约条款和法律程序——按加州法律，违反租约重要条款（先给书面纠正通知）或把房子用于违法用途，属于可以终止租约的「过错型正当理由」，但要走正式通知和法院程序，不能自己赶人。

核对日期：2026年11月11日。本页是一般信息，不构成法律或税务意见。

HOA 这一关

  • 很多小区的 CC&R 限制在住宅里经营生意，以你小区的文件为准。
  • HOA 要处罚时，Civil Code 5855 规定开会前至少 10 天书面通知业主，业主可以在会前纠正，纠正了就不能处罚。
  • 州法允许 HOA 禁止 30 天或以下的出租（Civil Code 4741），产妇住几周就走的模式，可能同时碰到这条。

尔湾市的规定

  • 居家营业：尔湾分区条例 2-14-2 要求在家经营要先有营业执照和居家营业许可（Home Occupation Permit）。批准标准以条例原文为准，大致包括：住宅不能是主要的服务地点，不能明显增加车流和人流，只能雇用住在屋里的人（或远程员工），不能有招牌。接收付费客人、雇用外来照护人员，看起来很难符合这些标准，最终以市政府认定为准。
  • 短租：尔湾禁止在住宅区做 30 天或以下的短租，也禁止为短租打广告，违者可能构成轻罪。谁要担责、怎么认定，以尔湾市条例原文和市政府认定为准。
  • 其他城市规定不同，以当地市政府为准。

保险

出租房的保险是按住宅出租来承保的。房子里在做生意，出了事故，保险公司是否赔，要看你的保单条款。发现情况后，尽快和保险经纪确认，并按保单要求通知保险公司。

房东该怎么做

  • 先核实事实：HOA 或邻居的投诉内容、日期、照片，不要只凭传言
  • 对照租约里的用途条款，书面通知租客停止经营、限期纠正
  • 收到 HOA 或市政府通知的，按期限书面回复，说明你已采取的措施
  • 租客不纠正的，请律师按 Civil Code 1946.2 和法定程序发终止通知；驱逐用时因法院和案件差异很大，无法承诺天数
  • 只针对商业经营这件事，不针对怀孕、刚生孩子或有小孩：家庭状况（familial status）是加州公平住房法保护的类别

举个例子

这是为了说明规则而设的例子，不是真实客户。孙先生在尔湾有一套独立屋，租给一对夫妇。半年后 HOA 来信，说邻居反映每周有不同的孕妇和护理人员进出、门口停满车。孙先生请物业拍照记录，确认屋里接收付费住客。他发书面通知，引用租约里「只作住宅使用」的条款，要求限期停止经营，并把通知抄给 HOA。租客停止经营后，他在 HOA 开会前提交了纠正说明。如果租客不停，他下一步会请律师按法定程序处理。
