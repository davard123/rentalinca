人在外地或国外远程投资，怎么判断物业管理人靠不靠谱、有没有乱收维修费？

靠事先写清的规矩和定期的账目来判断：签约时把要给你哪些报告、维修怎么审批、发票和照片怎么提供写进托管合同，之后每月对账、抽查发票；加州房地产局（DRE）建议房东核实执照、要求每月账目，并索取维修的报价、发票和付款凭证。

核对日期：2026年11月11日。本页是一般信息，不构成法律或税务意见。

该要的报告

  • 月度账目：当月收了多少租金，付了哪些费用，转给你多少，账上还剩多少。
  • 每笔维修的资料：报价、发票、付款凭证，修之前和修之后的照片。
  • 租约和押金资料：签好的租约、押金收据、入住和退房的检查照片。
  • 空置期的情况：挂牌、带看、收到几份申请。
  • 年度汇总：报税用的全年账目；你是非居民的，还有联邦 1042-S 和加州 592-B。

要事先书面约定的事

  • 多少钱以内可以直接修，超过要先问你，这个数由你定
  • 什么算紧急维修，紧急修完多久内通知你
  • 多大金额以上要几家报价
  • 物业和维修商有没有关系，要书面披露
  • 租金和押金放在经纪的信托账户（trust account），你可以要自己那份分户记录
  • 用什么方式沟通、几点回复，考虑时差
  • 怎么解约，解约时钥匙、押金和文件怎么交接

哪些情况要警惕

DRE 给房东的提醒包括：转给你的租金总是晚到或少了、支票跳票；物业不给发票证明费用真的发生并付了；不披露从你房子上得到的全部收入来源；不愿意见面。遇到这些，可以要求物业给出资金账目，也可以向 DRE 投诉。DRE 曾公布过物业公司员工伪造维修工单的执法案例，也提醒业主自己审批、核实维修，要求出示证明维修必要的记录。

举个例子

这是为了说明规则而设的例子，不是真实客户。赵女士住在北京，在橙县有两套出租房交给物业管理。某月对账单上同一套房一周内出现两笔水管维修。她按合同要求物业补上两张发票和修前修后的照片，发现第二笔是同一个漏点的返工。她和物业确认返工不应再收费，并把「返工不另收费、每笔维修附照片」补进了合同附件。

常见追问

DRE 建议房东发现账不清时要求物业提供资金账目，也可以向 DRE 投诉。要换物业的，先看合同里的解约条款和交接安排。

DRE 的消费者提示说，可以请经纪确认资金存进了名称正确的信托账户，并索取你自己那份分户记录（beneficiary record）核对。

替别人出租、招租、收租属于加州要持房地产经纪执照的业务（Business and Professions Code 10131）。DRE 的房东指南也写明，物业管理人收租和管理需要有效执照，驻场经理除外。执照可以在 DRE 官网查。
