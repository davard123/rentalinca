尔湾 HOA 能不能限制业主出租（最短租期、出租比例）？出租前要向 HOA 报备租客信息吗？

能限制一部分，但不能禁止：按加州 Davis-Stirling 法的 Civil Code 4741，HOA 不能禁止、也不能不合理地限制业主出租，出租比例的上限不能定得低于 25%，但可以禁止 30 天或以下的短租。报备方面，Civil Code 4740 写明按该条出租前，业主要向 HOA 提供取得产权日期的证明，以及租客的姓名和联系方式；很多小区的规章也要求登记，以你小区的文件为准。

核对日期：2026年11月11日。本页是一般信息，不构成法律或税务意见。

HOA 不能做的

  • 不能禁止出租：规章里禁止、实际上等于禁止、或不合理限制出租的条款，对业主没有约束力。这一条也保护 ADU 和 JADU（附属单元）的出租。
  • 出租比例不能低于 25%：HOA 不能把可出租的单位限制在 25% 以下，定得更宽可以。业主自住的单位，就算 ADU 租出去了，也不算在出租数里。
  • 旧条款不用等改：州法要求 2021 年 1 月 1 日起照此执行，不论规章改没改；董事会应在 2022 年 7 月 1 日前删改违规条款。
  • 故意违法有代价：故意违反这一条的 HOA，要赔实际损失，另付最高 1,000 美元的民事罚款。

HOA 可以做的

  • 禁止 30 天或以下的短租：州法明确允许。尔湾市本身也禁止在住宅区做 30 天或以下的短租。
  • 更长的最短租期：州法没有给出具体天数，只说不能「不合理限制」。你的小区要求更长的最短租期时，是否合理，要按具体条款问 HOA 的律师或你自己的律师。
  • 要求租客守小区规矩：停车、宠物、噪音、公共设施的规定，租客一样要遵守。HOA 要处罚时，书面通知的对象是业主。

房东该怎么做

  • 出租前读一遍 CC&R 和规章里关于出租的部分
  • 向管理公司要出租登记表，按要求提交产权日期证明和租客联系方式
  • 租期定在 30 天以上（尔湾市的标准是 31 天起）
  • 把 HOA 规章附在租约后面，让租客签收
  • HOA 拒绝或设限时，要求书面理由，对照 Civil Code 4741 核对

举个例子

这是为了说明规则而设的例子，不是真实客户。周先生在尔湾一个 condo 小区有一套房，准备出租。管理公司说小区规章规定出租单位不能超过 20%，现在名额满了。他对照 Civil Code 4741(b)，指出比例上限不能低于 25%，并书面要求 HOA 说明依据。HOA 的律师复核后，确认那条旧规定不能执行。他按要求登记了取得产权的日期和租客的联系方式，签了 12 个月的租约。

常见追问

要看名额是怎么定的。按 Civil Code 4741(b)，出租比例的上限不能低于 25%；定得低于 25% 的条款不能执行。比例在 25% 以上、确实满了的，要按小区规章的排队办法走，具体请律师看。

Davis-Stirling 法规定，HOA 收取的评估费或费用不能超过所需成本（Civil Code 5600(b)）。具体收不收、收多少，看小区的规章。

Civil Code 4740 写明，禁止出租的规定如果在你取得产权之后才生效，对你没有约束力。现在 4741 又进一步禁止了大部分限制出租的条款，两条可以对照着看。
