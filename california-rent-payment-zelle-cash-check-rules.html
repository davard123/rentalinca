收房租用 Zelle、支票还是现金？Zelle 转错或被骗怎么办？租客付现金要怎么留证据？

在加州，Zelle 和现金都可以收，但不能只收这两种：房东必须至少再给租客一种既不是现金、也不是电子转账的付款方式，比如支票或汇票（Civil Code 1947.3）。Zelle 属于电子转账，所以“只收 Zelle”也不行。收现金的，要当场开收据。

本页条文核对日期：2026年11月11日。本页是一般信息，不构成法律意见。

法律怎么规定

  • 至少一种非现金、非电子转账的方式：双方可以约定用现金或电子转账，但同时要允许另一种方式（1947.3(a)(1)、(e)）。
  • 只收现金的例外：租客的支票被退票或租客止付后，房东可以书面通知、附上退票的复印件，要求只付现金，最长三个月（1947.3(a)(2)）。
  • 支票不能收手续费：房东不得因租客用支票付租金或押金收费（1947.3(b)）。
  • 别人代付：第三方签了“我不是租客、付款不产生新租约”的确认书后，房东要接受代付（1947.3(a)(3)）。
  • 租约里放弃这些规定的条款无效（1947.3(f)）。
  • 租约要写明租金交给谁、用什么方式交；当面收的，要写明通常收租的日期和时间（Civil Code 1962）。

2026 年起：押金要按原方式退

如果押金或房租是用电子方式收的，退押金时要电子退到租客书面指定的账户，除非双方书面约定别的方式（Civil Code 1950.5(h)，AB 414）。平时用 Zelle 收租的房东，退租时不能只寄一张支票了事。

Zelle 的风险

  • 转错或被骗时，钱往往很难追回。发现问题，第一时间联系自己的银行。
  • Zelle 官方也提醒，只给信得过的人转账。
  • 遇到“多转了请退回”的要求，先在银行 app 里确认钱真的到账、来源是谁，再联系银行处理，不要直接转回给对方。
  • 请租客在备注里写明房屋和月份，方便对账。

收现金怎么留证据

  1. 当场开收据：日期、金额、哪个月的房租、双方签名，各留一份。
  2. 租客有权要求书面收据（Civil Code 1499）。
  3. 自己建一张收租台账，每笔都记。
  4. 能用支票或电子方式的，尽量少收现金。

举个例子

这是为了说明规则而设的例子，不是真实客户。张先生的租约只写了“租金用 Zelle 支付”。按 1947.3，这样不够，他在续约时补上“也可以用个人支票或汇票支付”，而且不收支票手续费。租客一年后退租，因为平时一直用 Zelle 交租，张先生按 1950.5 的要求，把押金余额电子退到租客书面指定的账户，并附上扣款明细。
