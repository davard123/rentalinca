带着租客卖出租房，要提前多久书面通知？租客不配合看房、也不想搬，怎么办？

可以带着租客卖，但房子卖了租约照样有效：固定租期的租客可以住到租约结束，新房东接手原来的租约；想交空房，只能等租约依法结束或租客书面同意搬走。有天数要求的是两件事：带人进屋看房要提前通知，以及想结束租约时要按法定天数和 AB 1482 的规则发通知。

本页条文核对日期：2026年11月11日。本页是一般信息，不构成法律意见。

卖了以后，租约和押金怎么办

  • 加州地产局的租房指南写明，房东自愿卖房不改变租客的权利，有租约的可以按原条件住到期满。新房东想结束月租（month-to-month）租约，也要依法、提前通知，受 AB 1482 约束的还要有正当理由（just cause）。
  • 押金二选一：扣除合法扣款后把余额转给买方，并书面通知租客转给了谁；或者直接退给租客，并给扣款明细（Civil Code 1950.5(i)）。过户前要给买方一份押金书面说明（1950.5(j)）。

买方要空房，怎么办

  • 买卖合同里不要承诺做不到的空房交付。
  • 月租租约：住满一年要提前 60 天书面通知，不满一年 30 天（Civil Code 1946.1）。另有一种 30 天的情形，要求买方是自然人、打算自住满一年、已开 escrow 等条件同时满足。
  • 受 AB 1482 约束的：“卖房”不在法定正当理由里。买方过户后想自住收回，条件很严：90 天内入住、住满 12 个月、给一个月租金的搬迁补偿；2020 年 7 月 1 日以后签的租约，还需要租客书面同意或租约里有相应条款（Civil Code 1946.2）。
  • 双方自愿：可以和租客商量提前搬走，条件写成书面协议，签之前请律师看。
  • 洛杉矶市、Santa Ana 等有本地条例的城市，还要按本地规定来。

带人看房怎么通知

  • 房东可以为了给买家看房进屋，但只能在正常工作时间（Civil Code 1954）。
  • 一般要书面通知，写明日期、大概时间和目的，24 小时推定为合理。
  • 如果 120 天内已书面告诉租客房子在卖、之后可能口头约看房，就可以提前 24 小时口头通知；进屋后要在屋内留下书面记录。
  • 不能滥用进屋权利骚扰租客。

卖房前的准备

  1. 找出租约，确认到期日和类型。
  2. 确认房子受不受 AB 1482 约束、所在城市有没有本地条例。
  3. 给租客书面的“房子在卖”通知，商量固定的看房时段。
  4. 和经纪一起决定是卖带租约的房子，还是等租约结束再卖。

举个例子

这是为了说明规则而设的例子，不是真实客户。陈太太的独立屋租约还有五个月到期，她想现在挂牌。她先书面告诉租客房子在卖，约好每周两个固定时段看房，每次看房前一天打电话确认。有一位自住买家希望交空房，她的经纪没有在合同里承诺空房，而是把过户日安排在租约到期之后，并提醒她租约到期时还要按 AB 1482 和本地规定核对能不能、怎么结束租约。

常见追问

先确认自己的通知合法合规。租客无理拒绝房东依法进屋，在 AB 1482 下属于可以终止租约的有过错理由之一，但走到这一步之前通常先沟通，必要时问律师。

二选一：扣除合法扣款后把余额转给买方，并书面通知租客；或者直接退给租客，并给出扣款明细（Civil Code 1950.5(i)）。

要看租约类型和是否受 AB 1482 约束。受约束时，自住收回有严格条件：90 天内入住、住满 12 个月、一个月租金的搬迁补偿；2020 年 7 月 1 日以后签的租约，还需要租客书面同意或租约里有相应条款。
