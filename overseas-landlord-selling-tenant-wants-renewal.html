人在国外，一直自己远程管钻石吧的出租房，租金比市价低，现在想卖，租客想再续一年，怎么处理？

看情况：你可以答应续约、带着租客卖，也可以不续，但能不能「不续」要先查租客是否受加州《租客保护法》（AB 1482）保护——租客连续合法住满 12 个月后，房东要有法定的「正当理由」才能终止租约，而「要卖房」本身不在法定理由里。

核对日期：2026年11月11日。本页是一般信息，不构成法律或税务意见。

先确认三件事

  • AB 1482 适不适用：自然人持有的独立屋或可单独出售的 condo，在租约里给过法定书面豁免通知的，一般可以豁免。没给过，就不要默认自己豁免。
  • 本地条例：查房子所在城市和县有没有自己的租客保护规定，以官方页面为准。
  • 租约状态：现在是固定租期还是已经转成月租。DRE 的租客指南写明，受正当理由保护的租约到期后自动转成月租继续，不是到期就结束。

三条路

一、续约，带着租客卖。DRE 写明：房东卖房，租客的权利不变，有租约的可以按原条件住到期满；押金要转给新业主或退给租客，并书面通知租客。带租客卖，买家多是投资客，低租金可能影响出价。

二、不续，空房卖。租客受 AB 1482 保护时，「要卖房」不是法定理由，只能用法定的无过错理由，比如业主或法定近亲自住、需要搬出的大修、撤出出租市场。能不能用「撤出出租市场」，要看你是不是真的不再出租这套房（加州司法部的解释是退出出租业务或改作出租以外的用途），不能拿来当卖房腾空的借口：卖不掉又重新出租，或买家接手后出租，都可能被认定为借口，房东可能要按 Civil Code 1946.2(h) 赔偿，后果见以卖房为由收回却没卖掉那一页。走这条路之前必须请律师评估；更稳妥的是和租客书面协商提前搬走。用法定理由终止时，通知里要写明理由，并给一个月租金的搬迁补助，或者书面免掉最后一个月租金；不严格照做，通知无效。租客住满一年的月租，州法要求房东提前至少 60 天书面通知。协商提前结束的，条款也请律师看。

三、先续一年，到期再说。受保护的租客，续约期满后照样转成月租，到时还是要有正当理由。续一年只是推迟决定，不会让到期时更容易收回。

人在国外，还要安排好这些

  • 带买家看房：Civil Code 1954 要求提前合理的书面通知，24 小时推定为合理，在正常工作时间进屋；如果 120 天内已书面告知房子在卖，之后可以电话通知，进屋后要留书面记录
  • 在本地找一个持牌经纪或托管方，负责看房、钥匙和送达通知
  • 外国人卖美国房产，一般由买方按成交金额的 15% 预扣（FIRPTA），卖前请会计师算

举个例子

这是为了说明规则而设的例子，不是真实客户。陈先生住在德国，在钻石吧有一套独立屋，租给一家人已经四年，月租比附近同类房子低一些，当初的租约里没有写豁免通知。他想卖房，租客希望再续一年。他先请律师确认 AB 1482 适用，于是比较了两条路：一是续约，把租约和租金情况写进卖房资料，卖给投资买家；二是请律师评估能不能以「撤出出租市场」为由书面终止，或者和租客书面协商搬走，再空房卖给自住买家。选哪条，取决于两种买家的出价差和空置期成本。

常见追问

DRE 的租客指南写明，房东卖房不改变租客的法律权利，有租约的可以按原条件住到期满。新业主要终止租约，同样要符合法律，受保护的租客仍然需要正当理由。

州法对卖给自住买家有一个 30 天通知的特别规定（Civil Code 1946.1(d)），条件包括已开 escrow、买家是自然人并打算自住至少一年等。但租客受 AB 1482 保护时，还要另外满足正当理由的要求。这种情况请律师逐条核对。

受 AB 1482 约束的，连续 12 个月累计涨幅不能超过上限；不受约束的，也要按租约和法定通知规则来。具体怎么算，见我们的涨租规则核对说明。
