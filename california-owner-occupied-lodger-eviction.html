华人长者把自住的独立屋分租给几个房客，房客不交租还威胁，屋主能直接请他走吗？

分租给几个人时，通常不能「直接请走」：Civil Code 1946.5 那套「书面通知期满后可请警方协助」的简易程序，只适用于屋主自住、而且只住了一个 lodger（寄宿房客）的情况；屋里住了两个或更多房客，就要按一般驱逐程序走法院。无论哪种情况，屋主自己换锁、断水电、扔东西都是违法的。

本页条文核对日期：2026年11月11日。本页是一般信息，不构成法律意见。

什么算 lodger

按 Civil Code 1946.5(c) 和法院自助中心的说明：你把自己家里的一个房间租给一个人；房子是你通常居住的地方；你保留进入所有房间、包括出租房间的权利，并整体管理这个家。租给不止一个人、你进不了那个房间、或者你自己不住在那里，就不是这种情况。

只有一个 lodger：简易程序

  1. 给书面终止通知。法院自助中心说明，期限一般等于付租周期，最少 7 天。通知按 Code of Civil Procedure 1162 规定的方式送达，或用挂号信、限本人签收并要回执。
  2. 期满不走，对方就没有权利再住。可以请警方按 Penal Code 602.3 协助，出示通知和送达证明。
  3. 不是每个警局都会出面；不出面，就要走驱逐诉讼。
  4. 对方留下的个人物品，要按 Civil Code 1980 起的规定处理。

两个及以上房客：一般驱逐程序

1946.5 和 602.3 都写明只适用于「只住一个 lodger」的自住房。屋里住了几个房客，就按一般程序：欠租的先送达 3 天付租或搬走通知，再向法院起诉，判决后由警长执行，步骤见欠租驱逐那一页。

正当理由（AB 1482）方面，Civil Code 1946.2(e) 对两种自住情形不适用：房客与自住业主共用厨房或卫生间；业主自住的独立屋，出租不超过两个单元或卧室。不属于这两种的，要另外判断。

房客威胁人身安全，先报警。驱逐属于法律事务，请找律师。

举个例子

这是为了说明规则而设的例子，不是真实客户。赵阿姨在圣盖博自住的房子里，把三个房间分别租给三个人。其中一人连续两个月不交租，还在厨房吵闹威胁。因为屋里不止一个房客，不能用 1946.5 的简易程序。赵阿姨先报警处理威胁，再请律师按欠租程序送达 3 天通知、走法院。

常见追问

不算。法院自助中心说明，房子要是你通常居住的地方；你不住在那里，就要走一般驱逐程序。

一般和付租周期一样长，最少 7 天。按月付租的，就给一个付租周期。
