## 结构与命令
`data/housing-news.json` 是唯一新闻数据源；不要手改生成区域。`scripts/news/sources.mjs` 是域名白名单与确定性解析器。

```sh
npm run news:update  # 官方来源检查；全部启用来源成功才写入，然后生成网页
npm run news:render  # 中文摘要修改后重新生成
npm run news:check   # 安全/日期/去重测试 + 生成结果一致性
npm run check       # 原站 JS 与租金事实同步检查
```

GitHub `Housing news source updates` 每周一 15:35 UTC 计划检查一次（夏令时洛杉矶周一 08:35，冬令时周一 07:35；调度可能延迟）。按用户要求取消维护代码推送触发，保留手动 workflow_dispatch 供故障排查。不依赖个人电脑在线。公开仓库标准 runner，无新增付费 API；需继续遵守平台免费配额与条款。公共仓库长期无活动时 GitHub 可能暂停定时工作流，管理员应留意 Actions 通知。

只有实际内容变化才提交四个数据/静态文件；不变不刷新同步时间。Vercel 沿用现有 main 分支 Git 部署，禁止强推。任一启用来源的网络/robots/解析失败时保留整份最后有效内容并让任务失败；详情见 Actions 记录。页面显示的是内容同步时间，不谎称每次检查都抓到了新闻。零合格新稿是正常结果，不填充凑数。

## 来源、时间和转载边界
- SCAG：`https://www.scag.ca.gov/news`，只处理具备明确日期的 /news/ 条目；有无日期的行政月报入口不当新新闻。使用原创标题与原文链接；已核实中文事实摘要注明出处。政策见 `https://www.scag.ca.gov/terms-use`；不复制第三方附件/照片。
- FHFA：`https://www.fhfa.gov/reports/house-price-index`，读取 release-date 表格，报告标题月份不当发布日期；季度/月度数据期另列。只收录官方原始发布。
- LAHD：`https://housing.lacity.gov/feed`。普通公开读取曾返回 200，但标识为本站爬虫的请求返回 403；不换身份规避。`automatic:false`，首条人工核实，保留官方直达链接。重新取得允许且真实测试通过前，不宣称该来源自动更新。
- C.A.R. 不接入自动转载：商业网站内容使用受其 site-terms 限制，未取得适用授权。不把会员身份推断为自动转载许可。
- 发布日期不等于生效日期；RSS/正文日期冲突必须注明。LAHD 首条 RSS 日期为 2026-08-20，正文页首为 2026-08-19，不能误称条例刚生效。
- 30 天以上明确显示较早发布；最多保留 120 天来源索引，按原日期排序，无伪造“今日更新”。客户端随实际日期更新新旧标签，不依赖有新稿才变旧。

## 中文摘要的人工核对流程
自动收录仅标题/日期/原文链接；不自动编造中文文章。添加摘要前打开原文核实范围和数字，填写 `title`、`summary`、`reviewedAt`，必要时加 `dataPeriod`/`dateNote`。不写没有依据的交易建议、确定收益、政策适用结论。原文标题或日期改变时自动撤下原摘要，留原文供复核；正文隐性修改无法仅靠列表检测，重要决策应再核原文。

首版已核实：SCAG 2026-09-02 发布的上半年住宅许可（约 27,000，同比增加约 5,000，非完工房源）；FHFA 2026-08-25 发布 Q2（同比 2.1%、环比 0.3%、6 月环比持平）；LAHD 租客反骚扰条例说明，仅明确洛杉矶市范围，不代替适用性法律审核。

## 安全与故障处理
来源只作为数据；不执行网页脚本或网页内指令。HTTPS 同主机跳转，禁止凭证/端口/查询请求；robots 每次检查；25 秒请求超时、最多 3 次跳转、2 MB 响应上限；HTML 转义与 JSON-LD `<` 转义。不下载正文到公开仓库。解析变更时先修最小合成测试，再真实 dry-run，不降级到猜日期或旧缓存冒充新数据。

工作流失败：看失败来源和状态码；403 不规避，暂停该源并如实更新说明。所有源失败时保留现有页面。生成检查失败先 `npm run news:render`；并发提交导致推送拒绝时重新运行，不 force push。
