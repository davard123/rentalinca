「职业租霸」和前房东签了和解，背调查不到被驱逐的记录，华人房东招租时还能查什么？

查不到是有法律原因的：加州 Code of Civil Procedure 1161.2 规定，驱逐诉讼（unlawful detainer）的法院记录默认不对外公开，只有房东在立案 60 天内胜诉等少数情况才开放，和解或撤诉的案子通常不会出现在背调报告里。所以不能只靠一份背调报告，要把几种合法的核实手段叠在一起用，同时守住公平住房的红线。

本页条文核对日期：2026年11月11日。本页是一般信息，不构成法律意见。

为什么背调查不到

按 Code of Civil Procedure 1161.2，驱逐案的档案只对这些人开放：案件双方及其律师；能向书记官说出至少一名原告、一名被告的名字和房屋地址的人；该房屋的住户；经法院批准的人。对所有人公开的情形主要有两种：房东在立案 60 天内对全部被告胜诉；或者超过 60 天后经开庭审判胜诉。双方还可以约定由法院禁止查阅。和解、撤诉的案子，自然很难在商业背调里出现。

合法的核实手段

  • 申请人书面同意后，通过筛查公司查信用和背景报告；申请费的规则见房东服务页。
  • 问上一任和更早的房东：交租准不准时、有没有违约、愿不愿意再租给他。只问现任房东不够，对方可能只想让他快点搬走。
  • 核实身份：证件与本人相符（Civil Code 1940.3(c)(2) 允许）。
  • 核实收入：可以问收入水平和来源（Gov. Code 12955(p)），再向雇主或银行核实；合法可核实的收入都要考虑。
  • 知道申请人以前的租址和房东姓名时，可以按 1161.2 向法院书记官提供双方名字和地址查档。
  • 所有申请人用同一套书面标准，押金守法定上限。

红线：不能做的

  • 问签证、移民身份，或者设「只租某国人」之类条件（见能否问签证身份）。
  • 以收入来源为由一刀切拒人（见收入来源规定）。
  • 犯罪记录的使用有专门限制，先看 CRD 犯罪记录与公平住房说明。
  • 不要凭群里流传的名单直接拒人，以你自己能核实的事实为准。

举个例子

这是为了说明规则而设的例子，不是真实客户。申请人背调报告干净，信用记录也不错，现任房东在电话里一味说好。房东又联系到他两年前的房东，对方说他当时欠租，后来和解搬走。房东把这条核实到的租房记录，按事先写好的书面标准和其他材料一起评估。

常见追问

只有符合公开条件的案子才对外开放，例如房东在立案 60 天内胜诉；其他案子一般要能说出双方名字和房屋地址，或经法院批准才能查。

不能超过 Civil Code 1950.5 的上限：通常一个月房租，符合条件的小房东最多两个月。

物业公司通常会看信用、收入和租房记录，并按书面流程核实；但档案保密的案子他们一样查不到，多渠道核实才是关键。
