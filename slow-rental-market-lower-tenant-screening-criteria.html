2026 年南加出租变慢，信用分等筛选门槛要不要降？

可以调，但要先想清楚两件事：降门槛换来的是更快租出，代价是欠租风险变大；而且不管怎么调，新标准都要事先写清楚、对所有申请人一样用，绝不能碰公平住房法保护的类别。

本页条文核对日期：2026年11月11日。本页是一般信息，不构成法律意见。

先确认问题真的出在门槛

如果来看房的人多、递申请的人少，问题多半在价格、房况或竞品，降门槛帮不上忙。只有在申请不少、却大多因为标准被拒的时候，才轮到考虑调整标准。

降门槛的风险，以及可以怎么补

信用分只是一项。放宽它，欠租的可能会变大。可以把重点放在更能说明问题的材料上：

  • 收入能不能核实：工资单、银行流水，或其他可核实的收入证明。
  • 以往的租房记录和前房东的评价。
  • 押金在法定上限内收足：一般最多一个月租金，符合条件的小房东最多两个月，租客是现役军人时除外（Civil Code 1950.5(c)）。

合法的边界（这一段最重要）

  • 标准要书面写出来：收申请费的，筛选标准要和申请表一起书面交给申请人，并按法定流程处理（Civil Code 1950.6）。
  • 不能问移民或公民身份，也不能要求对方声明身份（Civil Code 1940.3）。可以要证件和财务材料来核实身份和支付能力；没有 SSN 的，可以用护照等政府签发的带照片证件。
  • 不能因受保护类别区别对待：种族、国籍、公民或移民身份、主要语言、宗教、残障、性别、婚姻状况、家庭状况（有未成年孩子或怀孕）、收入来源、年龄等（加州公平住房法，见 CRD 和 DRE 指南）。
  • 收入来源受保护：收入不是工资的，要给申请人机会证明；用政府租金补贴的，按申请人自己要付的那部分租金算收入标准，并允许用其他可核实方式证明信用。
  • 犯罪记录有限制：不能一刀切拒绝所有有犯罪记录的人，未定罪的逮捕记录等不能看。
  • 放宽就对所有人一样放宽，不能看人松紧。

调整标准的步骤

  1. 把新标准写成书面文件，写明从哪天起适用。
  2. 附在申请表上，发给之后所有的申请人。
  3. 按收到完整申请的先后审核，留好记录。
  4. 拿不准某一条合不合法时，先问律师。

举个例子

这是为了说明规则而设的例子，不是真实客户。李女士的房子空了一个多月，她发现被拒的申请人里，有几位收入稳定、信用分却没达到她原来的线。她把标准改成书面的综合审核：信用报告、可核实的收入和前房东评价一起看，从某一天起对所有新申请适用，并附在申请表上。之后有一位申请人收入来自退休金，她按同一标准请对方提供退休金证明，审核通过。

常见追问

不可以。Civil Code 1940.3 禁止房东询问移民或公民身份，也不能要求对方作出相关声明。可以要求政府签发的带照片证件和财务资料，用来核实身份和支付能力。

不能只因为收入来源拒绝。加州公平住房法把收入来源列为受保护类别，收入不是工资的，要给申请人机会提供证明。

可以调整，但要写成新的书面标准，写明生效日期，对之后所有申请人一致适用，并保留记录。拿不准时请咨询律师。
