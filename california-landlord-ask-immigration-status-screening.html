加州房东筛租客，能不能问对方的签证、身份、家里几口人？「先查合法身份」这种建议合法吗？

签证和移民身份不能问：Civil Code 1940.3 明确禁止房东及其代理人询问租客、申请人或同住人的移民或公民身份，也不能要求对方声明或证明，所以「先查合法身份」在加州是违法做法。房东可以核实申请人是不是本人、付不付得起房租；可以登记谁会住进来，但不能因为家里有孩子而拒租或区别对待。

本页条文核对日期：2026年11月11日。本页是一般信息，不构成法律意见。

不能问、不能做的

  • 问签证类型、有没有绿卡、是不是公民。
  • 要求出示签证页、移民文件来「证明合法身份」。
  • 以向移民局或执法部门举报相威胁、逼租客搬走（Civil Code 1940.2(a)(5)），或为骚扰、逼迁而向他人透露租客身份（1940.3(b)(3)），CRD 也明确禁止。
  • 因原国籍、主要语言、移民或公民身份、家庭状况（有 18 岁以下孩子或怀孕）拒租、加租或拖延维修。

可以做的

  • 核实身份：1940.3(c)(2) 允许房东为核实申请人或同住人的身份要材料，例如核对护照或驾照与本人一致。
  • 核实财务条件：同一款允许为核实财务条件要材料，例如收入证明、存款证明。
  • 遵守联邦法律义务：1940.3(c)(1) 保留了遵守联邦法律的情形，例如联邦租金补助项目。CRD 说明，申请某些联邦资助的可负担住房或美国农业部乡村住房时可能有例外。
  • 登记入住人员：可以登记有几个人、各是谁会住进来，但家庭状况受保护，不能拿来排斥有孩子的家庭。

房东怎么改流程

  1. 申请表删掉签证类型、国籍、移民身份这类栏目。
  2. 身份核实只看证件是否与本人相符，不记录签证信息。
  3. 所有申请人用同一套书面标准。
  4. 经纪和物业同样受 1940.3 约束，委托前确认他们的流程。
  5. 拿不准时问律师，或看 CRD 的说明。

举个例子

这是为了说明规则而设的例子，不是真实客户。张先生在华人房东群里看到「先查合法身份再租」的建议，就在申请表加了一栏「签证类型」。按 1940.3，这一栏不应出现。改法是删掉这一栏，只核对护照照片页与申请人本人一致，再按统一标准看收入证明和租房记录。

常见追问

看财务条件：收入和存款能否支付租期内的房租。法律允许为核实财务条件要材料，这比猜对方的身份可靠。

1940.3 同样约束房东的代理人（agent），经纪和物业也不能问。

可以登记入住人数和同住人，但家庭状况是受保护类别，不能因为有孩子而拒租、加价或设更高门槛。
