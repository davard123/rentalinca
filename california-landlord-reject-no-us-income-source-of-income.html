房东要求「本地收入」「美国信用」，以此拒掉收入在国内的陪读家庭，算不算违法歧视？

有明显的违法风险：加州公平住房法（FEHA，Gov. Code 12955）禁止按「收入来源」（source of income）歧视，也保护原国籍和移民身份，只要申请人的收入合法、能核实，房东不应因为钱来自国内就一律拒绝。房东可以核实收入和支付能力，问题出在「只认本地收入」这种一刀切的条件。法条没有逐字提到海外收入，个案是否违法由 CRD 或法院判断。

本页条文核对日期：2026年11月11日。本页是一般信息，不构成法律意见。

法律怎么定义

  • Gov. Code 12955(p) 把收入来源定义为「lawful, verifiable income」，即合法、可核实的收入，直接付给租客或代租客付给房东的都算。
  • 同一条规定，房东书面或口头询问收入水平和来源，本身不算歧视。
  • 加州法规 2 CCR 12140 列举的合法可核实收入包括工资、利息和投资分配，以及家庭成员代付的款项等。
  • 加州民权部（CRD）列出的受保护类别包括原国籍、公民身份、移民身份、主要语言、家庭状况和收入来源。
  • 例外：CRD 培训材料说明，业主自住、只出租屋里一个房间的，不受收入来源规定约束。

能做和不能做

可以：用同一套书面标准核实每个申请人的支付能力；要求银行流水、存款证明、在职收入证明及翻译件；为核实身份和财务条件要证件和材料（Civil Code 1940.3 允许）。

不能：广告写「只收本地收入」「不租陪读」；只要求中国申请人多交钱、多交材料；问签证和移民身份；因为家里有孩子而拒租。

房东的做法

  1. 把筛选标准写下来，对每个申请人一样。
  2. 收入证明接受多种合法形式，包括海外工资、存款和家人资助。
  3. 核实真实性：请银行直接出具证明、向雇主核实。
  4. 拒绝时写明客观理由，记录留档。
  5. 拿不准就问熟悉公平住房的律师。

举个例子

这是为了说明规则而设的例子，不是真实客户。陈太太带孩子来尔湾读书，丈夫在国内工作，每月汇款，名下有存款。房东甲回复「我们只接受美国收入」，这种回复有歧视风险。房东乙让所有申请人交同一套材料，陈太太交了收入证明和翻译件、银行流水、存款证明，房东按同一标准评估后再做决定。

常见追问

可以。Gov. Code 12955(p) 写明，询问收入水平和来源不算歧视；关键在于问了之后用什么标准做决定。

可以把信用记录当作参考之一。申请人没有美国信用记录时，接受其他合法可核实的支付能力证明，并对所有人一视同仁，更稳妥。

可以向加州民权部 CRD 投诉（calcivilrights.ca.gov/complaintprocess），也可以找律师。
