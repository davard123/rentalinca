陪读妈妈带孩子在尔湾租房，没有美国收入，只有国内存款和国内工资，能过房东审核吗？

有机会过，关键在于材料能不能让房东容易核实：加州法律保护合法、可核实的收入来源，国内工资、存款利息、家人汇款只要拿得出证明，都可以用来说明你付得起房租。每个房东的书面标准不同，能不能过要看具体房源；但「只认美国收入、一律拒绝」有违反收入来源保护的风险，法条没有逐字提到海外收入，能不能算违法由 CRD 或法院按个案判断。

本页条文核对日期：2026年11月11日。本页是一般信息，不构成法律意见。

你可以依靠的规则

  • Gov. Code 12955 保护「合法、可核实」的收入来源；加州法规 2 CCR 12140 列举的合法收入包括工资、利息和投资分配、家庭成员代付的款项。
  • 原国籍、移民身份、家庭状况（有 18 岁以下孩子）都是受保护类别（CRD）。
  • 房东不能问你的签证和移民身份（Civil Code 1940.3），但可以为核实身份和财务条件要证件和收入材料。

材料清单

  • 身份：护照。
  • 收入：国内单位开的在职收入证明、近期工资流水，附英文翻译。
  • 存款：银行出具的存款证明、近几个月流水；钱已经转到美国的，附美国银行对账单。
  • 家人资助：汇款记录和一份资助说明。
  • 租房记录：以前房东的推荐信或联系方式，有就附上。
  • 一页说明信：家庭情况、资金来源、打算住多久。

材料越容易核实越好：写清银行和单位的联系方式，翻译件和原件对应，同一套材料给每个房东。

被卡住时的选项

  • 提供担保人。
  • 预付房租：租期 6 个月以上时预付不少于 6 个月是法条不禁止的，但一次付很多钱有风险，先读预付房租那一页。
  • 押金不能超过法定上限，多收的不要答应。
  • 遇到「只收美国收入」直接拒，可以礼貌提出提供替代材料；觉得被歧视，可以向 CRD 咨询或投诉。

举个例子

这是为了说明规则而设的例子，不是真实客户。李女士带孩子到尔湾，丈夫在国内上班。她准备了护照、丈夫单位的收入证明和翻译件、国内银行存款证明、转到美国账户后的对账单，以及一页说明信。第一位房东说只考虑有美国收入的人；她换了一套房，那位房东按统一标准看完全部材料，再和她谈租约。

常见追问

一般不能。Civil Code 1940.3 禁止房东询问或要求说明移民、公民身份；但为核实身份和财务条件，房东可以要护照和收入材料。

用其他合法可核实的支付能力证明补上，例如存款证明、收入证明、担保人，并在说明信里主动讲清楚。

不一定，接不接受由房东决定，而且要符合 Civil Code 1950.5 的规定，细节见预付房租那一页。
