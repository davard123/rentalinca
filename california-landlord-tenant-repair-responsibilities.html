出租房哪些维修必须房东负责，哪些（下水道堵、后院园艺）可以写进租约让租客负责？

影响“能不能住”的维修，最终责任在房东，写进租约也推不掉；不影响居住的项目，比如后院园艺，可以在租约里约定由租客负责；下水道堵要看原因，租客使用不当造成的由租客负责。

什么能写进租约让租客负责

  • 法律允许双方约定，由租客维修或维护全部或指定的部分，作为租金对价的一部分（Civil Code 1942.1）。
  • 加州地产局指南解释：这种约定要出于诚意，租金要真有相应减少，租客也有能力做；房东仍对符合住房法规负最终责任；入住后不能单方面把维修责任转给租客。
  • 让租客放弃影响居住的维修权利的条款无效（1942.1）。

下水道堵、园艺怎么分

下水道：租客把油、湿巾等冲下去造成的，属于使用不当，由租客负责；管道老化或树根造成的，属于房东要维持正常的管道系统。建议请疏通师傅书面写明原因。园艺：一般不属于居住条件，可以写进租约由租客日常养护，写清范围，比如浇水、除草，大树修剪由谁负责。

房东不修，租客能做什么

房东接到通知后过了合理时间（30 天推定为合理）仍不修影响居住的问题，租客可以自己修了从房租里扣，费用不超过一个月租金，12 个月内最多两次；问题是租客自己造成的除外（Civil Code 1942）。

举个例子

这是为了说明规则而设的例子，不是真实客户。孙女士把独立屋出租，租约写明“后院浇水除草由租客负责，大树修剪由房东安排”。半年后厨房下水道堵了，疏通师傅书面写明是油污堆积。按租约和 1941.2，这次疏通费由租客承担。又过了几个月，热水器坏了，属于冷热水供应，由孙女士负责尽快修好。

常见追问

对影响居住的问题，让租客放弃这些权利的条款无效（Civil Code 1942.1）。法律允许的是双方约定由租客负责某些部分，作为租金对价的一部分，房东仍对符合住房法规负最终责任。

在法定条件下可以：通知房东后过了合理时间（30 天推定为合理）仍不修，费用不超过一个月租金，12 个月内最多两次；问题是租客自己造成的除外（Civil Code 1942）。

日常养护按租约由租客做。影响居住的问题，以及租约没交给租客的部分，仍由房东负责。
